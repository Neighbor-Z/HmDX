# HmDX 很萌下载器

HLS/m3u8 Downloader X (HmDX) 是一款M3U8网络视频下载工具。




# 软件功能

- 支持多线程下载HLS切片。
- 支持HLS直播录制。
- 支持下载自动纠错。支持2-Pass自动校验。
- 支持使用 FFmpeg 软件进行MP4、TS格式封装。支持RAW输出。
- 支持自定义附加选项。
- 批量任务管理和启动。


# 系统要求

适用于Windows 7及以上操作系统。

您需要自主携带 ffmpeg.exe 才能够使用MP4、TS格式封装功能。
